# MAISON BEAUTY

Сайт-визитка студии красоты. Демонстрационный проект портфолио Liberté Digital.

## Запуск
Откройте index.html в браузере. Сборка и установка пакетов не нужны.

## Файлы
- index.html: разделы сайта
- style.css: оформление и адаптация
- app.js: прайс, галерея, FAQ и подготовка сообщения для записи
- DESIGN.md: визуальные принципы

Контакты задаются в CONTACTS в app.js. Пока они не указаны, реальная запись недоступна. Цены и фото демонстрационные. Фотографии загружаются с Unsplash, шрифты с Google Fonts.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
