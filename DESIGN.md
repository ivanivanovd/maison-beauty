# MAISON BEAUTY

Portfolio concept for a local beauty studio in Nalchik. Reference: supplied beauty layouts, plus Apple design analysis for whitespace, restrained UI, frosted navigation and photography hierarchy. Not an Apple visual clone.

Palette: warm white #FCFAF8, ink #423533, Rosewood action #96515B (darkened for readability), blush #F7C8D3. Typography: Cormorant Garamond for editorial headings, Manrope for Russian body/UI; serif and Arial fallbacks. Spacious responsive sections, thin dividers, glass only on navigation and two small panels. Abstract petal sculpture created in CSS. No long dashes in visible copy.

Interaction: service category tabs with keyboard navigation, service-specific booking dialog, message composition and copying, accessible native FAQ disclosure, portfolio lightbox, mobile navigation. Real contact destinations are intentionally unset in dist/app.js CONTACTS. Add a WhatsApp number and Telegram username to enable direct messenger links. Demo clearly marked, no invented client results or testimonials. Photography uses Unsplash remote images; fonts use Google Fonts. Internet access is required for those assets; system typography and colored image backgrounds provide fallbacks.
